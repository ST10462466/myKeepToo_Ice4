KeepToo Transaction History

> Project Description
KeepToo Transaction History is a Java desktop application developed using Java Swing in NetBeans.
The application recreates a transaction history interface where users can view and filter transaction records.

> Features
- **Transaction History:** Displays transaction records in a table.
- **Filtering:** Provides dropdown menus to filter or select transaction information.
- **Resizable Interface:** Uses Swing panels and a scroll pane to help
  the table adjust when the application window is resized.
- **User Interaction:** Includes event handling for interface components.
- **Close Button:** Allows users to close the transaction history window.

> Technologies Used
- Java
- Java Swing (`JFrame`, `JPanel`, `JTable`, and `JScrollPane`)
- NetBeans IDE

> How to Run
1. Open the project in NetBeans.
2. Locate the main application class.
3. Run the project to open the Transaction History window.

> Project Purpose
The purpose of this project is to practise creating graphical user interfaces (GUIs) using Java Swing,
arranging components with panels and layouts, and adding basic functionality through event handling.
